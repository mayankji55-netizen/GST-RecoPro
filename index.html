B2B Invoices

Paste rows copied from your GSTR-2B Excel "B2B" sheet, columns in this exact order (tab-separated — copying straight from Excel works):
GSTIN of supplier  |  Trade/Legal name  |  Invoice number  |  Invoice type  |  Invoice Date  |  Invoice Value  |  Place of supply  |  Reverse Charge (Y/N)  |  Taxable Value  |  IGST  |  CGST  |  SGST  |  Cess

Credit / Debit Notes (CDNR)

Paste rows from GSTR-2B "B2B-CDNR" sheet, columns in this order:
GSTIN of supplier  |  Trade/Legal name  |  Note number  |  Note type (Credit Note/Debit Note)  |  Note Date  |  Note Value  |  Place of supply  |  Reverse Charge (Y/N)  |  Taxable Value  |  IGST  |  CGST  |  SGST  |  Cess
2B Credit Note auto-matches Books "Debit Note"; 2B Debit Note auto-matches Books "Credit Note".

All 2B rows

Tip: type in any column's search box (below its header) to filter — e.g. type a party name in the Trade Name box.

Books Purchase Register

Paste rows from your Tally / accounting purchase register, columns in this order:
Date  |  Particulars (Supplier name)  |  Party GSTIN  |  Vch Type  |  Vch No.  |  Doc No.  |  Doc Date  |  Taxable  |  IGST  |  CGST  |  SGST
Vch Type must be exactly one of: Purchase, Purchase Services, Debit Note, Credit Note, Journal.

All Books rows

Tip: type in any column's search box (below its header) to filter — e.g. type a party name in the Particulars box.

RCM Purchases as per Books

Paste your reverse-charge purchase entries — columns in this order:
Date  |  Particulars  |  Party GSTIN  |  Vch Type  |  Vch No.  |  Taxable  |  IGST  |  CGST  |  SGST

Security & Users

☁ Cloud Database & Companies

GST RecoPro cloud mode uses Supabase for one central database across companies and devices. Each company has its own isolated workspace. Cloud authentication uses Supabase Auth; company access is controlled by PostgreSQL Row Level Security.

Data & Settings

Best practice: connect a data file using the bar at the top (Create new / Open existing). Every change then auto-saves into that file, so you can replace or update this app file any time — just open the same data file again. Without a data file, data lives only in this browser and can disappear when the app file is replaced or moved.
